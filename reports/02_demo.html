02. AI-generated text detector: heatmaps and usage

Summary. Eleven word-level heatmap cards from the reference model (runs/lic3_nano_r10/model.pt): mixed texts with exact AI spans (Claude-written spans, RAID sentence splices, open-model continuations and edits) and pure AI or human texts from TextSight 2026. Word-level AUROC on Claude-written spans is 100.0 and document IoU 98.6; on OpAI-Bench mixed texts the word AUROC is 72.8. A 512-token document takes 0.15 s on 8 CPU cores and 0.90 s on one core (int8). Usage: aidetect/predict.py prints the document score and writes an HTML heatmap. Generated 2026-11-18 20:14 UTC.

Figure 1. Word heatmaps on mixed and pure texts

Each word is shaded by the mean P(AI) of its tokens (the token head). Dotted underline marks words inside a true AI span. The first four cards are real Claude-written spans inside human-origin text (Heterogeneous AI Spans test set), the next three are RAID splices that alternate sentences of a human text and an AI text written for the same prompt (held-out source documents), then two human Stack Exchange and PubMed passages continued by the open generators (gen_mixed), then one fully AI and one fully human passage from TextSight 2026. For a mixed text the document score estimates the share of AI text. 2. How the scores are computed

  • Word score. The mean probability of the tokens ending inside the word, from the token head. The shading in the cards is this probability.
  • Document score. The length-weighted mean of the document logits of 1,024-token windows (the last window is anchored to the end), passed through a sigmoid. For a mixed text it estimates the share of AI text, not a yes or no; the evaluation tables in the runs report threshold it at 1% false positive rate on human text.
  • Speed. int8 dynamic quantization of the attention and MLP up projections (MLP down projections and heads stay fp32) matches fp32 accuracy on CPU; see the CPU table in the runs report.

3. Use the detector

export V45_DATA_ROOT=/data18/voyage_4_5_experiments
M=$V45_DATA_ROOT/data/aidetect/runs/lic3_nano_r10/model.pt        # default (round 2 final); lic5_nano_r15 is the round-4 alternative
python aidetect/predict.py --model $M --file doc.txt --html heat.html            # document score, per-word scores, heatmap card
python aidetect/predict.py --model $M --file doc.txt --device cpu --quant 2      # int8 on CPU

# from Python
import sys; sys.path.insert(0, 'aidetect')
from infer import Predictor
P = Predictor(M, device='cpu', quant=2)
r = P.predict([text])[0]          # r['doc_prob'], r['tok_prob_mean'], r['words'] = [(start, end, p_ai), ...]

The weights are fp32 (1.4 GB; the frozen embedding table is most of it). Windows of 1,024 tokens are scored independently, so long documents scale linearly.
